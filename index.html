Documentation

Learn how to use Galaxy to manage dependencies in your Nova projects.

Installing Packages

To install a package globally from the registry, simply run:

nova galaxy install <package_name>

Project Initialization

You can initialize a new Nova project using a boilerplate template hosted on Galaxy:

nova galaxy init <template_name>

Module Resolution

When you compile a Nova project using nova build, the compiler will automatically look for imports inside your local galaxy_modules/ directory as well as the standard library.

Contribute

Galaxy is a fully static, Git-backed registry. There is no central database or authentication. To publish your package, you simply open a Pull Request to our GitHub repository.

How to Publish a Package

  1. Host your Nova library publicly on GitHub.
  2. Ensure your repository has a descriptive README.md.
  3. Fork the nova-programming/galaxy-registry repository.
  4. Create a new JSON file in the packages/ folder named after your package (e.g. my-package.json).

JSON Schema

Your JSON file must follow this structure:

{
  "package": "my-package",
  "github_repo": "yourusername/my-package",
  "version": "1.0.0",
  "author": "Your Name",
  "description": "A brief description of what your package does.",
  "tags": ["cli", "utility"],
  "download_url": "https://github.com/yourusername/my-package/archive/refs/heads/main.zip"
}

Submit your Pull Request, and upon approval, your package will instantly be available globally via nova galaxy install.
