Contribute

Galaxy is a fully static, Git-backed registry organized into three trust tiers.

Tiers

  • Core — maintained by the Nova core team. Ships with the runtime.
  • Verified — human-reviewed for code quality and security. Promoted from Community.
  • Community — auto-published via PR. Anyone can contribute.

How to Publish

All new submissions go to the Community tier. Verified status is earned through upvotes and human review.

  1. Host your Nova library on GitHub.
  2. Run galaxy init library my-lib to generate metadata.
  3. Run galaxy publish to open a PR to the registry.

Your package JSON must follow this schema:

{
  "package": "my-lib",
  "tier": "community",
  "github_repo": "yourusername/my-lib",
  "version": "1.0.0",
  "author": "Your Name",
  "description": "A brief description.",
  "tags": ["utility"],
  "download_url": "https://github.com/yourusername/my-lib/archive/refs/tags/v1.0.0.zip"
}
