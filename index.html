Contribute

Galaxy is a fully static, Git-backed registry organized into three trust tiers.

Tiers

  • Core — maintained by the Nova team. Ships with the compiler.
  • Verified — human-reviewed for code quality. Promoted from Community.
  • Community — auto-published via PR. Anyone can contribute.

How to Publish

All new submissions go to the Community tier. Verified status is earned through upvotes and human review.

  1. Host your Nova library on GitHub with a README.md.
  2. Run galaxy init library my-lib to generate galaxy.json.
  3. Run galaxy publish to open a PR to the registry.
