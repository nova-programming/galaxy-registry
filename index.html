Get Started with Nova & Galaxy

                
Install the native compiler and package manager in 60 seconds.


                
1. Install the Nova Toolchain

                
macOS / Linux (bash):

                
curl -fsSL https://galaxy-registry.vercel.app/install.sh | bash

                
Windows (PowerShell):

                
powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri https://galaxy-registry.vercel.app/install.ps1 -OutFile install.ps1; powershell -ExecutionPolicy Bypass -File install.ps1"

                
Python Fallback (any OS):

                
curl -fsSL https://galaxy-registry.vercel.app/install.py | python


                
2. Verify Installation

                
nova --version
galaxy --version


                
3. Create Your First Native App

                
// app.nv
import gui

app = gui.App("My First Nova App", 640, 480)
col = gui.Column()
col.add(gui.Title("Hello World!"))
col.add(gui.Text("Running at 60 FPS natively."))
app.set_root(col)
app.run()

                
Run immediately with:

                
nova run app.nv


                
4. Package Management with Galaxy

                
galaxy init library my-lib    # Scaffold new library
galaxy install nova-math      # Install package
galaxy add nova-http          # Add dependency to galaxy.json
galaxy publish                # Publish with SHA-256 integrity

Publish & Contribute to Galaxy

                
Galaxy is an open, Git-backed package registry for the Nova language. Anyone can create and publish a package.


                
Trust Tiers

                
    
                    
  • Core — Runtime packages maintained directly by the Nova core compiler team.
    • 
                    
  • Verified — Human-reviewed for code security, type safety, and architectural standards.
    • 
                    
  • Community — Openly published packages pinned with SHA-256 release checksums.
    • 
                


                
Publishing Workflow in 4 Steps

                
    
                    
  1. Create your library: galaxy init library my-lib
    2. 
                    
  2. Configure galaxy.json with name, license, repo URL, and keywords.
    3. 
                    
  3. Push your repository to GitHub.
    4. 
                    
  4. Run galaxy publish to compute hashes and submit your package!
    5. 
                


                

                    Automated Review & Promotion
                    Community packages with 50+ upvotes or verified maintainer identity are automatically queued for promotion to the Verified tier.
