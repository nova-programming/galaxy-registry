Get Started with Galaxy

Install the CLI, create a library, publish to the world.

1. Install galaxy CLI

No Python required — native installers for every platform:

macOS / Linux (bash):

curl -O https://galaxy-registry.vercel.app/install.sh && bash install.sh

Windows (PowerShell):

Invoke-WebRequest -Uri https://galaxy-registry.vercel.app/install.ps1 -OutFile install.ps1; powershell -File install.ps1

Python fallback (any platform):

curl -O https://galaxy-registry.vercel.app/install.py && python install.py

The installer downloads the Nova compiler and Galaxy CLI to %LOCALAPPDATA%\nova\ (Windows) or ~/.nova/ (Unix), creates launchers, and adds to your PATH. Open a new terminal and run:

nova --version
galaxy --version

2. Create a library project

galaxy init library my-lib
cd my-lib

Use the library template for reusable Nova modules. See the Templates reference for full details.

Your galaxy.json is auto-generated. Edit it to set your name, license, GitHub repo, and keywords.

3. Write code

Add Nova source files to src/. The main file is src/main.nv (or the file specified in galaxy.json under "main").

4. Install from the registry

galaxy install nova-math
galaxy install nova-http

You can also install directly from GitHub:

galaxy install owner/repo

5. Publish your library

From your library directory, run:

galaxy publish

This validates your galaxy.json, computes SHA-256 hashes of your source files, and opens a pre-filled GitHub Issue on the galaxy-registry repository. The registry maintainers will review and merge your submission.

6. Stay updated

nova --version            # Check Nova version
nova update               # Update Nova compiler
galaxy --version          # Check Galaxy version
galaxy update             # Update Galaxy CLI
galaxy upgrade [pkg]      # Update installed packages
galaxy info nova-http     # Package details
galaxy remove nova-math   # Uninstall

Contribute to Galaxy

Galaxy is a fully static, Git-backed registry with three trust tiers. Anyone can contribute — all submissions start in the Community tier.

Trust Tiers

  • Core — maintained by the Nova team. Ships with the compiler runtime.
  • Verified — human-reviewed for code quality and security. Promoted from Community.
  • Community — published via galaxy publish. Anyone can submit.

How to Publish (galaxy publish)

The recommended way to publish is through the Galaxy CLI:

  1. Write your Nova library and host it on GitHub
  2. Run galaxy init library my-lib to scaffold the project structure
  3. Edit galaxy.json — set your name, repo URL, license, description, keywords
  4. Run galaxy publish from your project root

galaxy publish validates your manifest, computes SHA-256 hashes of every source file, and opens a pre-filled GitHub Issue on the registry repository. No direct write access needed.

From Community to Verified Packages with 50+ upvotes are automatically queued for promotion review. A human reviewer verifies code quality, and if approved, the package moves to the Verified tier.

Tier Rules

  • Global uniqueness — no duplicate names across tiers
  • Monotonic versions — versions must increase, no downgrades
  • Immutable tier — packages stay at their current tier (promotion is the only direction)
  • No repeats — once a version is published, it cannot be republished

GitHub Actions Automation

  • PR Validation — schema checks, name uniqueness, monotonic version enforcement
  • Auto-Quarantine — packages with 5+ flags are automatically quarantined
  • Promotion Queue — community packages with 50+ upvotes are flagged for review
