Nova Language Documentation

Welcome to the official documentation for Nova. Whether you are a newcomer to programming looking to write your first script, or a seasoned systems engineer aiming to write high-performance bare-metal OS kernels, this guide covers everything you need to know.

Why Nova? (The Philosophy)

Modern developers are often forced to make a difficult choice: write in a high-level language like Python to iterate quickly but suffer from terrible runtime performance, or write in C/C++ to get maximum speed but suffer through manual memory management and massive gigabyte-sized compiler toolchains (like GCC or MSVC).

Nova eliminates this compromise.

  • 14x Faster than Python: Nova is not interpreted. It compiles directly down to pure x86 machine code. In heavy computational benchmarks, Nova scripts execute 14 times faster than Python equivalents.
  • Near-C Performance Out of the Box: Nova sits right next to highly optimized C code in benchmarks, achieving near-parity with GCC -O3 flags.
  • Zero Dependencies: The Nova compiler is entirely self-hosted. It features its own built-in lexer, parser, assembler, and linker. You do not need to download gigabytes of C++ build tools. A single, tiny executable is all you need to compile Windows PE executables or bare-metal OS flats.
  • Pythonic Syntax: You get the raw metal speed of C, but you write code that looks as simple and clean as Python.

The Basics (For Beginners)

Nova is designed to be easy to read and write. Here are the absolute basics of the language.

Hello World

To print text to the screen, use the print keyword. This invokes highly optimized native C-level printf equivalents under the hood.

print("Hello, World!")

Variables & Data Types

Variables hold data. Nova uses static type inference, meaning it automatically figures out what kind of data you are using, but you can also explicitly declare them.

  • int: Whole numbers (e.g., 42, -10)
  • float: Decimal numbers (e.g., 3.14). Processed using the hardware x87 FPU.
  • string: Text (e.g., "Nova is fast")
  • bool: True or False values.
  • list[T]: Dynamic arrays. e.g., a list of numbers. Nova automatically protects you from crashing by checking list boundaries safely.

Making Decisions (If / Else)

You can tell your program to take different paths using if statements.

age: int = 18

if age >= 18 {
    print("You are an adult.")
} else {
    print("You are a minor.")
}

Repeating Actions (Loops)

Instead of copying and pasting code, use a for loop to repeat actions.

# Prints numbers 1 through 5
for i = 1 to 5 step 1 {
    print(i)
}

# Loops can also go backwards
for x = 10 downto 1 step 1 {
    print(x)
}

Functions & Classes

As your programs grow, you'll need to organize your code into reusable blocks.

Functions

Use the def keyword to create a reusable block of code. Functions compile down to standard x86 call and ret routines.

def add_numbers(a: int, b: int) -> int {
    return a + b
}

result = add_numbers(10, 5)
print(result) # Prints 15

Object-Oriented Classes

Nova supports defining objects with properties and methods. Method calls use "dynamic dispatch" (vtables) natively.

class Player {
    health: int
    
    # The __init__ method sets up the object when it's created
    def __init__(starting_health: int) {
        self.health = starting_health
    }
    
    def take_damage(amount: int) {
        self.health = self.health - amount
    }
}

Unique & Advanced Features

For advanced developers, Nova brings powerful, unique tools not commonly found in high-level languages.

1. Unsafe @raw Blocks (Inline Assembly)

Nova allows you to drop directly into inline x86 assembly anywhere in your code. This is uniquely powerful for system-level programming and manual optimization.

Example: Fast inverse square root 
def fast_inv_sqrt(number: float) -> float {
    @raw {
        mov eax, dword [ebp+8]  ; Load float bytes
        shr eax, 1              ; Bitwise shift right
        mov ecx, 0x5f3759df     ; Magic constant
        sub ecx, eax
        mov dword [ebp-4], ecx  ; Store result
    }
}

2. Zero-Cost Debug Printing

The printd keyword acts as a native debug assertion. It only compiles to assembly when the --debug flag is passed to the compiler. In production, it costs zero CPU cycles.

Example: Logging high-frequency loops 
for i = 0 to 1000000 step 1 {
    # In production, this emits ZERO assembly instructions.
    # In --debug mode, it prints: "debug - [line 42]: 500"
    printd(i)
}

3. Static Duck Typing (The has Keyword)

Nova features the has keyword to statically verify if a data structure possesses a specific field at compile time.

Example: Safe generic serialization 
def serialize(entity: any) {
    if entity has score {
        print("Entity score is:")
        print(entity.score)
    }
}

4. Built-in CSPRNG (ChaCha20)

Nova natively embeds a Cryptographically Secure Pseudorandom Number Generator (ChaCha20) into the runtime. You don't need external libraries to generate secure keys or randomness.

Example: Generating a secure salt 
# random() is auto-seeded securely at startup via OS tick count
const secure_salt = random()

5. Pointer Suffix Directives

Unlike C which uses confusing asterisks, Nova uses explicit suffix properties to read and write arbitrary memory sizes from raw pointer addresses.

Example: Custom memory allocator tracking 
def write_header(memory_ptr: int, size: int) {
    # Write a 4-byte dword at the exact memory address
    memory_ptr.value_dword = size
    
    # Write a 1-byte flag directly after it
    flag_ptr = memory_ptr + 4
    flag_ptr.value_byte = 1
}

Native OS Integration

Nova talks directly to the host Operating System (Windows/Linux) via built-in standard library wrappers.

  • sys_get_args(): Extracts CLI arguments (strips quotes automatically).
  • sys_system(cmd): Executes shell sub-processes.
  • sys_exit(code): Terminates the process immediately.
  • sys_get_tick_count(): Returns system uptime in milliseconds.
  • File I/O: open(path, mode), read(fd), write(fd, content), close(fd).

Compiler Architecture

When running nova_main.exe build, the self-hosted compiler executes in a single pipeline without invoking GCC:

  1. lexer.nv: Tokenizes source characters into a stream of structured Token structs.
  2. parser.nv: Constructs a syntax tree (AST) via recursive-descent parsing and performs aggressive constant folding.
  3. type_checker.nv: Infers and validates static types.
  4. codegen.nv: Generates Intel-syntax x86-32 assembly lines. Injects list/array bounds checking and maps variables to esi/edi registers (Variable-to-Register Promotion).
  5. assembler.nv: Encodes assembly to native machine code bytes (in-process).
  6. linker.nv: Packages machine code into a valid Windows PE binary natively.

Tree-Shaking Dead Code Elimination: The compiler builds a dependency graph of function calls and dynamically slices out unused standard library routines, which reduces final binary sizes by up to 70%.
