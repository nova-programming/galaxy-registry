Functions & Control Flow

Uses standard cdecl calling convention. Loops support both index tracking and item iteration.

def calculate(a: int, b: int) -> int { if a == null { return 0 } for i = 0 to 10 step 1 { print(i) } return a + b }

Native Structs (data)

Define tightly packed C-style memory structures. Offsets are calculated statically.

data Vector3 { x: int y: int z: int } def move(v: Vector3) { v.x = v.x + 10 }

Object-Oriented (class)

Dynamic dispatch with virtual method tables (vtables) automatically managed by the compiler.

class Entity { id: int def __init__(start_id: int) { self.id = start_id } }

API / Networking

Make REST calls out-of-the-box using the built-in compiler networking pipeline.

# Native network request req = api("https://api.github.com") if req.status() == 200 { print(req.json()) }

Built-in Functions

len(var) / sizeof(var)

len() evaluates dynamic bounds (strings, lists) or calls __len__ on objects. sizeof() resolves compile-time byte sizes.

sys_system(cmd)

Execute shell sub-processes dynamically (WinExec wrapping).

random()

Cryptographically secure 32-bit random number generated via unrolled ChaCha20 blocks.

open(path, mode)

Native file descriptor access. Returns FD integer. Use with read(fd) and write(fd, val).

The @raw Block

Nova restricts pointer arithmetic and assembly generation to blocks explicitly marked with @raw to ensure safety elsewhere.

@raw { ptr = alloc(4) # Allocate 4 bytes on Heap ptr.value = 100 # Write dword # Inline x86 assembly mov eax, ptr.value push eax free(ptr) # Deallocate }
Pointer SuffixOperation
ptr.value / ptr.value_dwordReads/Writes 32-bit (4 bytes) at address.
ptr.value_wordReads/Writes 16-bit (2 bytes) at address.
ptr.value_byteReads/Writes 8-bit (1 byte) at address.
ptr.addrReturns the raw memory address integer.
ptr.isValid / ptr.isNullChecks if address is != 0 or == 0.
