Unsafe Blocks & Pointers

Drop down to raw memory control and inline assembly with the @raw directive. Perform manual heap allocations instantly.

# Allocate memory and write pointer bytes def manual_mem() { @raw { ptr = alloc(4) ptr.value_dword = 42 free(ptr) } }

Native C-Structs

Define tightly packed data structures using the data keyword for high-performance memory alignment.

data Vector3 { x: int y: int z: int } def calculate(v: Vector3) { v.x = v.y + v.z }
